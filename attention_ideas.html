Novel Attention Compression Methods

基于 MLA (Multi-Head Latent Attention) 的发散思考 — 4 种新型注意力压缩机制

Baseline: MLA 已有方法

DeepSeek-V2/V3/V4 低秩分解 RoPE/NoPE 分离

核心公式

标准注意力需要缓存完整的 $K, V \in \mathbb{R}^{n \times d}$，MLA 改为缓存压缩后的 latent：

$$h \xrightarrow{W_{down}} c \in \mathbb{R}^{r} \xrightarrow{W_{up}^K, W_{up}^V} K, V$$

KV Cache 从 $n \times 2d$ 降到 $n \times r$，其中 $r \ll d$。

RoPE 部分单独存储（不压缩），NoPE 部分通过 latent 压缩缓存。

压缩比

$$\text{Compression} = \frac{2d}{r + d_{rope}} \approx 3\times$$

💡 Idea 1: Delta-Compressed Attention (ΔCA) 很可行

视频编码启发 时序冗余 与 MLA 正交

灵感来源

视频编码 (H.264) 的 I 帧 + P 帧 策略：关键帧精确存储，中间帧只存差值。

核心观察

连续 token 的 KV 向量高度相似。MLA 把每个 token 当独立的来压缩，完全忽略了时序冗余。

算法

每隔 $B$ 个 token 存一个完整的关键帧 $k_{anchor}$，中间只存差值并低秩压缩：

$$c_i = k_i - k_{\lfloor i/B \rfloor \cdot B}$$ $$\tilde{c}_i = W_{down} \cdot c_i, \quad W_{down} \in \mathbb{R}^{r \times d}, \quad r \ll d$$

还原时：

$$\hat{k}_i = k_{\lfloor i/B \rfloor \cdot B} + W_{up} \cdot \tilde{c}_i$$

数据流图

Token: t0 t1 t2 ... t7 t8 t9 ... | | | | | | Type: anchor delta delta delta anchor delta | | | | | | Store: [full d] [comp r] [comp r] [comp r] [full d] [comp r] ↑ ↑ └──── 关键帧间隔 B=8 ──────────────────────┘

缓存大小分析

$$\text{Cache}_{ΔCA} = \underbrace{\frac{n}{B} \cdot d}_{\text{关键帧}} + \underbrace{n \cdot r}_{\text{压缩差值}} = n \left(\frac{d}{B} + r\right)$$

取 $B=8, r=d/4$：

$$\text{Compression} = \frac{2d}{\frac{d}{8} + \frac{d}{4}} = \frac{2d}{\frac{3d}{8}} \approx 5.3\times$$

关键：差值的低秩性

为什么差值可以用更低的秩压缩？因为：

$$\text{Var}(c_i) = \text{Var}(k_i - k_{anchor}) \ll \text{Var}(k_i)$$

差值集中在一个更小的子空间里。直觉上：相邻 token 关注的"内容"相似，差异主要在局部语义微调。

✓ 优势

  • 与 MLA 正交，可叠加使用
  • 思路直觉、实现简单
  • $W_{down}, W_{up}$ 端到端可训
  • $B$ 可调节压缩比 vs 精度

✗ 挑战

  • 关键帧边界处的不连续性
  • 长距离依赖的差值可能不再低秩
  • 训练时需 teacher forcing anchor
  • 预填充阶段无明显加速
核心 insight：MLA 压缩特征维度的冗余，ΔCA 压缩时序维度的冗余。两个维度的冗余是独立的，所以可以叠加。

💡 Idea 2: Implicit Neural KV Cache (INKV) 需验证

NeRF 启发 神经隐式表示 极限压缩

灵感来源

NeRF 用一个小 MLP 隐式表示整个 3D 场景。类比：用小网络隐式编码整个 KV Cache。

核心思想

不存 KV 向量本身，而是存一个能"回忆"任意位置 KV 的小网络：

$$k_i = f_\theta(\text{PE}(i), z_i), \quad v_i = g_\theta(\text{PE}(i), z_i)$$

其中 $f_\theta, g_\theta$ 是极小的 MLP（2 层，宽度 64），$z_i \in \mathbb{R}^{z_{dim}}$ 是每个 token 的低维"指纹"，$\theta$ 在推理时在线拟合。

架构图

┌─────────────────┐ position i ──→ │ Positional │ │ Encoding PE(i) │──┐ └─────────────────┘ │ ┌──────────┐ ├──→ │ MLP f_θ │ ──→ k_i token finger- ┌────────────┐ │ │ (tiny, │ print z_i ───→ │ Stored per │ ──────┘ │ 2-layer)│ ──→ v_i │ token (16d)│ └──────────┘ └────────────┘ ↑ θ 在线拟合 (每 token 几步 SGD)

缓存大小分析

$$\text{Cache}_{INKV} = \underbrace{|\theta|}_{\text{MLP 参数}} + \underbrace{n \cdot z_{dim}}_{\text{token 指纹}}$$

设 $|\theta| = 10K$ 参数，$z_{dim} = 16$，$d = 4096$，$n = 100K$：

$$\text{标准} = 100K \times 2 \times 4096 \approx 800M \quad \text{vs} \quad \text{INKV} = 10K + 100K \times 16 \approx 1.6M$$

压缩 ~500×（理论上限，实际取决于拟合精度）

混合策略：近精确 + 远模糊

$$\text{Cache} = \underbrace{[\text{精确 KV}]}_{\text{最近 } W \text{ 个 token}} \cup \underbrace{[f_\theta, g_\theta, \{z_i\}]}_{\text{更早的 token（隐式）}}$$

类似人类记忆：近期记忆精确，远期记忆模糊但高度压缩。

✓ 优势

  • 理论压缩比极高
  • 缓存大小与序列长度弱相关
  • 天然支持超长上下文
  • 可与滑动窗口注意力结合

✗ 挑战

  • 在线拟合速度是瓶颈（推理延迟）
  • 小 MLP 容量有限，长序列信息丢失
  • 训练时如何端到端优化？
  • 拟合误差对注意力质量的影响未知

💡 Idea 3: Stochastic Rank Attention (SRA) 很可行

Dropout 反向思维 随机矩阵理论 训练即一行代码

灵感来源

Dropout：训练时随机丢弃 → 推理时保持全部。

SRA 反其道：训练时用随机变化的压缩秩 → 推理时用固定低秩。

算法

训练时，每个 forward pass 随机选择压缩秩：

$$r_t \sim \text{Uniform}(r_{min}, r_{max})$$ $$K = W_{up}[:, :r_t] \cdot W_{down}[:r_t, :] \cdot h$$

推理时，固定 $r = r_{min}$，获得最大压缩。

为什么有效？隐式核范数正则化

设投影矩阵的奇异值为 $\sigma_1 \geq \sigma_2 \geq ... \geq \sigma_d$，维度 $i$ 在训练中被保留的概率为：

$$P(i \text{ 被保留}) = P(r_t \geq i) = \frac{r_{max} - i + 1}{r_{max} - r_{min} + 1}$$

高编号维度被选中的概率低。梯度期望：

$$\mathbb{E}\left[\frac{\partial \mathcal{L}}{\partial \sigma_i}\right] \propto P(i) \cdot \frac{\partial \mathcal{L}}{\partial \sigma_i}$$

效果等价于对投影矩阵施加加权核范数正则化：

$$\mathcal{L}_{implicit} \propto \sum_{i} w_i \cdot \sigma_i, \quad w_i = 1 - P(i)$$

模型被迫把重要信息集中到前几个奇异方向 → 低秩时信息损失最小。

伪代码

def forward(self, h): if self.training: r = random.randint(self.r_min, self.r_max) # 随机秩 else: r = self.r_min # 推理时最大压缩 latent = h @ self.W_down[:r, :].T # [B, S, r] K = latent @ self.W_up_K[:, :r].T # [B, S, d] V = latent @ self.W_up_V[:, :r].T # [B, S, d] return K, V

✓ 优势

  • 实现极简（改一行代码）
  • 无额外参数、无额外计算
  • 可直接应用于 MLA
  • 理论优雅（隐式正则化）

✗ 挑战

  • 额外压缩比有限（~2×）
  • $r_{min}$ 选择敏感
  • 训练不稳定风险（秩变化太剧烈）
  • 需要从头训练（不适用于已有模型）
最 elegant 的想法：不改架构，不加参数，仅通过训练策略让模型"主动"把信息集中到低秩子空间。

💡 Idea 4: Tensor-Train Attention (TTA) 需验证

量子启发 张量网络 高阶相关性

灵感来源

量子计算中的张量网络 (Tensor Train)：用链式低秩张量乘积表示高维对象。

核心思想

把 $d$ 维 KV 向量视为 $m = \log_2 d$ 个 "qubit" 的联合状态，用 TT 分解：

$$k_i[j_1, j_2, ..., j_m] = G_1^{(i)}[j_1] \cdot G_2^{(i)}[j_2] \cdot \ldots \cdot G_m^{(i)}[j_m]$$

每个核心 $G_l^{(i)} \in \mathbb{R}^{r \times 2 \times r}$（$j_l \in \{0,1\}$），总参数：

$$\text{TT 参数} = m \cdot 2r^2 \quad \text{vs} \quad \text{原始} = d = 2^m$$

直觉图示

标准 KV 向量 (d=4096): k = [k_1, k_2, k_3, ..., k_4096] → 存 4096 个数 TT 分解 (m=12 qubits, rank r=4): k ≈ G₁ — G₂ — G₃ — ... — G₁₂ → 存 12 × 2 × 4² = 384 个数 │ │ │ │ j₁ j₂ j₃ j₁₂ (每个 jₗ ∈ {0,1}) 压缩比: 4096 / 384 ≈ 10.7×

vs 低秩分解 (MLA)

$$\underbrace{k = W \cdot c}_{\text{MLA: 捕捉线性相关性}} \quad \text{vs} \quad \underbrace{k = \text{TT}(G_1, ..., G_m)}_{\text{TTA: 捕捉高阶非线性相关性}}$$

MLA 的低秩分解只能捕捉维度间的二阶相关性（协方差矩阵），TT 可以捕捉任意阶相关性。

注意力计算

TT 格式下，内积 $q^T k$ 可以高效计算，无需还原完整向量：

$$q^T k = \text{tr}\left(\prod_{l=1}^{m} \sum_{j_l} Q_l[j_l] \otimes G_l[j_l]\right)$$

复杂度 $O(m \cdot r^4)$ vs 原始 $O(d) = O(2^m)$，在 $r$ 小且 $d$ 大时有优势。

✓ 优势

  • 压缩比高（~10×）
  • 捕捉高阶相关性
  • 数学理论完善（张量网络）
  • 可控制压缩精度（调 rank $r$）

✗ 挑战

  • 反向传播通过 TT 链较复杂
  • GPU 不擅长小矩阵连乘
  • 正交化/稳定化需额外操作
  • 实际 wall-clock 加速不确定

推荐研究路线

短期（低风险）： 先在本项目的 110M 模型上实验 SRA（改一行代码）和 ΔCA（实现简单），验证压缩效果和损失。

中期（中等风险）： 实验 TTA，需要实现 TT 前向/反向传播，但数学框架成熟。
